# Audiobooks

Coloque aqui os MP3 de cada módulo, com o nome referenciado no campo `audio`
de src/data/modules.ts.

Exemplo: `modulo-01.mp3` → no módulo, `audio: 'modulo-01.mp3'`.

O player só aparece quando o campo está preenchido, e some sozinho se o arquivo
não for encontrado — a página nunca quebra por falta de áudio.
